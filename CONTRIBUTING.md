## General
- Test backed code changes
- Tests can be run from the command line inside the devcontainer (-headless suffix)
- Test can be run using the `Run Extension Test` task in the vscode Run and Debug view
- New code matches existing style (enforced via eslint)
- Be kind and respectful

## Where to start
- Bug fixes always welcome
- New feature proposals go through a github issue or discussion

## Agentic Coding
- Small PRs (~300 lines or less required) where the human understands the changes end to end
- No PRs driven by Agents, only human interactions in the PR comments / discussions
- Agents can be used to refine text or look for spelling errors / grammar
  - We welcome the human roughness, though! Bonus points in the current era.
